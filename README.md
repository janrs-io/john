# John — Engineering Notes & Portfolio

Personal technical blog and portfolio built with **Astro** & **Tailwind CSS**, deployed on **Cloudflare Pages**.

- **Live Site**: [https://john.janrs.com](https://john.janrs.com)
- **Focus**: Go, High-Concurrency Backend Systems, Bare-Metal Kubernetes HA, Linux Internals, Next.js / Astro, PostgreSQL, and Cloudflare Edge.

## Local Development

```bash
npm install
npm run dev
```
